search

: web and code search in your terminal. A fast TUI and CLI for DuckDuckGo, Google, Bing, Kagi, Brave, GitHub, Sourcegraph and more, with DuckDuckGo-style !bangs, copyable code snippets and summaries computed on your own device. One small static binary for Linux, macOS and Windows, from a Raspberry Pi to a 4K monitor. demo video

Try it

    nix run github:heywoodlh/tui-search -- "nixos flakes tutorial"

    search                               # open the TUI
    search "rust lifetimes"              # results + summary, inline
    search '!w alan turing'              # !bangs pick the engine
    search -e gh -c -l go NewProgram     # GitHub code search
    search -E                            # write the query in $EDITOR
Single-quote queries containing ! in bash and zsh (history expansion).

Features

- Engines: DuckDuckGo (default), Google, Bing, Kagi, Brave, Mojeek, SearXNG, Wikipedia, Stack Overflow, Hacker News, GitHub, GitLab, Sourcegraph, Codeberg, and your own URL, JSON or HTML engines. Engines needing keys stay hidden until set. - Bangs: !g !ddg !w !so !gh !ghc !sg ... plus ~40 that open in your browser (!yt !aw !nix !hm !mdn). Tab completes them. - Code: Line-numbered fragments; copy them, or open the full file in $EDITOR at the matching line. - Summaries: Extractive, on-device, no model files: consensus across results, or of a fetched page. Optional local LLM hook. - TUI: Vim keys, arrows and mouse; configurable keybindings; a status bar with hints; Esc always goes back; Tab opens an engine picker; Ctrl+L jumps to the search bar; ctrl+w splits panes like vim to compare engines side by side. - Layouts: Split preview on wide screens, stacked on phones, tablets and tmux panes; reflows live on resize. - Themes: Catppuccin, Dracula, Nord, Gruvbox, Solarized, Tokyo Night and more, foreground-only: your terminal background stays. - Config: One TOML file; credentials from env, files or commands (pass, op, gh auth token); a home-manager module. - Small: Static Go binary, capped downloads, low_power mode.
